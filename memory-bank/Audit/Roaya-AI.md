## Add schema and technical signals

Implement structured data as valid JSON-LD. It will not guarantee an AI mention, but it helps search engines and retrieval systems understand the identity and relationships behind your pages.

- `Organization` markup on the homepage.
- `LocalBusiness` markup on the Contact page.
- `WebSite` markup on the homepage.
- `Service` markup on all service pages.
- `ContactPoint` markup for sales, support, and security contacts.
- `FAQPage` markup only for FAQs visibly shown on the same page.
- `BreadcrumbList` markup across all inner pages.
- `Review` markup only for genuine, attributable reviews that meet platform rules.
- `VideoObject` markup if you publish useful demos, onboarding, migration, or explainer videos.
- `Article` markup for original guides, thought leadership, comparison content, and technical documentation.

Also verify these technical basics:

- One canonical URL per page.
- HTTPS on every resource and redirect from HTTP.
- XML sitemap submitted to Google Search Console and Bing Webmaster Tools.
- Valid `robots.txt` that does not block key service pages, CSS, JavaScript, images, or approved crawlers.
- Correct `meta robots` directives: no accidental `noindex`, `nofollow`, or canonical conflicts.
- Fast mobile performance and low layout shift.
- Human-readable URL structure, such as `/services/cloud`, `/services/business-email`, `/trust/security`.
- Descriptive page titles and unique meta descriptions.
- One clear H1 per page and logical H2/H3 hierarchy.
- Descriptive internal links—not generic “Read more” or “Learn more.”
- Image alt text that describes important product visuals and screenshots.
- Accessible HTML tables rather than feature information embedded only in graphics or PDFs.
- A reliable site search, if schema includes `SearchAction`.
- Arabic and English pages connected through accurate `hreflang` annotations.
